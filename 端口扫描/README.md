## 功能特性

| 模块 | 说明 |
|------|------|
| **主机发现** | ICMP Ping + TCP 多端口 Ping，自动识别存活主机 |
| **端口扫描** | 多线程 TCP Connect 扫描 + UDP 扫描，支持 1-65535 全端口 |
| **Banner 抓取** | 对开放端口发送针对性探测包，抓取服务 Banner |
| **服务识别** | 内置 140+ 端口服务映射表 + 系统 `getservbyport` 补充 |
| **版本识别** | 从 Banner 中正则提取 SSH/HTTP/服务器等软件版本 |
| **Web 指纹** | 识别 Apache / Nginx / IIS / Tomcat / Jetty 等 Web 服务器 |
| **漏洞标记** | 内置 60+ 高危端口库(关联 CVE)，红色高亮标记 |
| **OS 猜测** | 通过 TTL 值推测操作系统(Windows / Linux / 网络设备等) |
| **弱口令爆破** | SSH / MySQL / MSSQL 自动弱口令爆破 |
| **报告导出** | JSON / CSV / HTML 可视化报告三种格式 |
| **进度显示** | 实时显示扫描进度、速率、预计剩余时间 |

```bash

# 直接运行（无需 pip install 任何包）
```

## 使用方式

### 命令行模式

```bash
# 扫描整个 C 段（常用端口）
python 全网段扫描端口.py -t 192.168.1.0/24

# 全端口扫描 + 跳过存活探测 + 1000 线程
python 全网段扫描端口.py -t 192.168.1.0/24 -p all --no-ping --threads 1000

# 指定自定义端口 + 导出 JSON 和 HTML
python 全网段扫描端口.py -t 10.0.0.1-10.0.0.254 -p 80,443,3306,6379 -o html

# TCP + UDP 双协议扫描
python 全网段扫描端口.py -t 192.168.1.0/24 --proto both

# 域名扫描
python 全网段扫描端口.py -t example.com -p common

# 混合目标
python 全网段扫描端口.py -t 192.168.1.0/24,baidu.com -p 22,80,443

# 启用弱口令爆破
python 全网段扫描端口.py -t 192.168.1.0/24 -p common --brute

# 自定义密码字典
python 全网段扫描端口.py -t 192.168.1.0/24 --brute --dict my_passwords.txt
```

### 交互模式

直接运行脚本，进入引导式交互界面：

```bash
python 全网段扫描端口.py
```

按提示输入目标地址、端口范围、扫描协议、线程数等参数即可。

## 命令行参数

| 参数 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| `--target` | `-t` | 目标地址 (IP/域名/CIDR/范围) | 必填(命令行模式) |
| `--ports` | `-p` | 端口范围 `common`/`top1000`/`all`/自定义 | `common` |
| `--proto` | - | 扫描协议 `tcp`/`udp`/`both` | `tcp` |
| `--threads` | - | 并发线程数 | `500` |
| `--timeout` | - | 连接超时时间(秒) | `2.0` |
| `--no-ping` | - | 跳过存活探测，直接扫描 | 关闭 |
| `--ping-method` | - | 存活探测方式 `icmp`/`tcp`/`both` | `both` |
| `--output` | `-o` | 输出格式 `json`/`csv`/`html`/`all`/`none` | `all` |
| `--output-dir` | - | 报告输出目录 | `./reports/` |
| `--brute` | - | 启用弱口令爆破 | 关闭 |
| `--dict` | - | 自定义密码字典路径 | `password_dict.txt` |

## 扫描模块详解

### 主机发现

扫描前先探测主机存活状态，避免大量无效连接。

- **ICMP Ping**: 发送 ICMP Echo Request，获取 TTL 值用于 OS 猜测
- **TCP Ping**: 对 80/443/22/445/3389 等常用端口尝试 TCP 连接，适用于禁用 ICMP 的主机
- 两种方式可组合使用，也可通过 `--no-ping` 跳过直接扫描全部目标

TTL 与操作系统对应关系：

| TTL 范围 | 猜测操作系统 |
|----------|-------------|
| ≤ 32 | 路由器 / 嵌入式设备 |
| 33 - 64 | Linux / Unix / macOS |
| 65 - 128 | Windows |
| 129 - 255 | Cisco / Solaris / 网络设备 |

### 端口扫描

**TCP Connect 扫描**: 标准 `connect()` 系统调用，稳定可靠，全程多线程并发。

**UDP 扫描**: 发送针对性探测包，通过 ICMP 不可达或 UDP 响应判断端口状态。采用二次确认机制区分 `open` 和 `open|filtered`。

**扫描模式**:

| 模式 | 命令 | 端口数 | 适用场景 |
|------|------|--------|---------|
| 快速扫描 | `-p common` | ~200 | 日常巡检 |
| 标准扫描 | `-p top1000` | 1000 | 常规评估 |
| 全端口扫描 | `-p all` | 65535 | 深度审计 |
| 自定义 | `-p 80,443,3306` | 自定义 | 专项检查 |

### Banner 与指纹识别

对以下常见协议发送专用探测包以获取准确的服务 Banner：

| 端口 | 协议 | 探测方式 |
|------|------|---------|
| 80/8080 | HTTP | `GET / HTTP/1.0` 请求 |
| 443 | HTTPS | ClientHello 握手 |
| 22 | SSH | 等待服务器 Banner |
| 3306 | MySQL | 等待握手包 |
| 6379 | Redis | `PING` 命令 |
| 3389 | RDP | TPKT 连接请求 |
| 9200 | Elasticsearch | `GET /` 请求 |
| 25/587 | SMTP | `HELO` 命令 |

内置 **60+ 高危端口库**，涵盖 Metasploit 默认端口、Redis 未授权访问、Docker API、Elasticsearch RCE 等常见攻击面。

### 弱口令爆破

自动对扫描中发现的 **SSH (22)**、**MySQL (3306)**、**MSSQL (1433)** 端口进行弱口令爆破。

- **SSH**: 优先使用 `paramiko` 库，回退到 `plink`/`sshpass` 方案
- **MySQL**: 纯 socket 实现 `mysql_native_password` 认证协议
- **MSSQL**: 纯 socket 实现 TDS PRELOGIN + LOGIN7 协议

内置 **133 条**常用弱口令字典（`password_dict.txt`），支持自定义字典文件。

```bash
# 命令行启用爆破
python 全网段扫描端口.py -t 192.168.1.0/24 --brute

# 自定义字典
python 全网段扫描端口.py -t 192.168.1.0/24 --brute --dict my_dict.txt
```

## 报告导出

支持三种报告格式，文件命名格式为 `scan_{目标}_{时间}.{扩展名}`，输出到 `./reports/` 目录。

### JSON

包含完整扫描元信息、每台主机的端口列表、Banner 指纹、爆破结果等结构化数据。

### CSV

表格格式，包含 16 列字段：IP、主机名、OS 猜测、TTL、端口、协议、服务、状态、Banner、版本、高危、漏洞说明、响应时间、爆破成功、爆破用户名、爆破密码。

### HTML

深色主题可视化报告，包含：

- 统计卡片（总目标数、存活主机、开放端口、高危端口、爆破成功、平均响应）
- 热门开放端口 Top 20 柱状图
- 服务分布 Top 15
- 每台主机可折叠的端口详情表（端口号、服务、状态、响应时间、TTL、版本、Banner 指纹、风险标记）
